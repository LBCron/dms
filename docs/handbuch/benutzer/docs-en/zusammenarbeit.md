# Notes, mentions, history {#notizen-erwahnungen-historie}

## Notes {#notizen}

Notes are short, formatted texts on a Mappe – "Called Mr Özdemir, he's coming on Friday". They don't belong to any field and don't need a Mappe type that provides for them.

![Notes on a Mappe](bilder/notizen.png)

- Every Mappe has its own tab **Notes** for them, directly before the **History**; the number next to it says how many there are. If someone mentions you in a note, the Mappe opens right there.
- Every note shows who wrote it when and who last changed it.
- **Everyone** may change and delete notes – like slips of paper in a shared folder. The [history](#historie) keeps visible what happened.
- With the tick **Notes** next to the search field, the search also searches the notes.
- You can also mention someone with **@** in notes.

## Mentions {#erwahnungen}

In formatted texts and notes you mention a user with **@**: type **@** and the first letters, and the suggestions appear right where you are writing; choose with ↑/↓, accept with Enter or Tab, Esc closes. The user gets a [task](eingang.md), and the Mappe appears under "To do" for them until they complete it.

- If you save the text again, no second task is created.
- If you remove the mention again, the task stays open; the history records that it was removed.
- If you mention yourself, you don't get a task.

## History {#historie}

If the Mappe type has a tab **History**, it shows the story of the Mappe, newest first:

- created and changed – expanded with every changed field, **before** and **after**,
- documents uploaded and deleted,
- put in the recycle bin and restored,
- notes, tasks and mentions, passed-on tasks,
- e-mails sent – with a link to the e-mail,
- who displayed a password (never the password itself; changed passwords only appear as "changed").

![History of a Mappe](bilder/protokoll.png)

Entries with a **▸** in front can be expanded; at the end it says what's behind them (e.g. "3 fields", "before/after", "2 attachments"). **Expand all** opens all at once. Names lead to the user's Mappe.

Entries cannot be changed or deleted. The history begins with version 0.12; older changes are not recorded, and entries before version 0.12.1 partly have fewer details.
