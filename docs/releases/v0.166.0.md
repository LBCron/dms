## Pakete erfahren auch von anderen Mappentypen

- **Ereignisse zu fremden Mappentypen:** Ein Paket kann jetzt auch auf Mappen anderer Pakete reagieren – zum Beispiel erfährt eine Vertragsverwaltung, wenn mit einem Vertragspartner etwas passiert. Im Manifest nennt es dafür fremde Mappentypen (`basis:organisation`, `dms:post`) oder `*` für alle, die es lesen darf. Die Rechte-Vorschau bei Installation und Update zeigt sie an; ändern sie sich, musst du ein Update neu bestätigen.
- **Nur was das Paket lesen darf:** Ein Ereignis zu einer Mappe kommt nur an, wenn das Paket genau diese Mappe gerade lesen darf. Sonst geht still nichts hinaus, der Grund steht im Protokoll.
- **Pakete am Mappentyp:** Im Mappentyp-Editor gibt es den neuen Abschnitt *Pakete*. Er zeigt, welche Pakete Mappen dieses Typs lesen dürfen; mit einem Haken verwehrst du einem einzelnen Paket den Mappentyp ganz – es liest und ändert dann keine solchen Mappen mehr und bekommt keine Ereignisse dazu. Das wirkt sofort.
