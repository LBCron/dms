## Korrigiert

- **Handbuch online wieder aktuell** (#846). help.ablago.app wurde seit 0.175 nicht mehr aktualisiert, weil die Seite mit über 150 Handbuch-Versionen größer war, als GitHub Pages erlaubt. Online gibt es jetzt nur noch das Handbuch zur neuesten Version unter `…/aktuell/`.
- Alte Adressen mit Versionsnummer (`…/admin/v0.22/sicherung/`) oder `…/entwicklung/` führen auf dieselbe Seite in der aktuellen Fassung, gibt es sie dort nicht, auf die Startseite des Handbuchs.
- Das Handbuch deiner Version bringt Ablago weiter selbst mit, auch ohne Internet: Hilfe im Menü und jedes **?** öffnen es.

## Technik

- Veröffentlicht wird über GitHub Actions (`actions/upload-pages-artifact`, `actions/deploy-pages`) aus dem Release-Lauf, nicht mehr über den Zweig `gh-pages`. `veroeffentlichen.py` stellt die Seite neu zusammen und bricht ab, wenn sie über 900 MB käme.
- Versionsauswahl (`versions.json`, `extra.version` in `mkdocs.yml`) und der Hinweis „nicht die neueste Version“ entfallen. `handbuchOnlineUrl` zeigt immer auf `aktuell`, `handbuchVersion` entfällt.
