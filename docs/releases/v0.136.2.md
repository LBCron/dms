## Behoben

- **Englische README mit englischen Bildern** (#574): `README.en.md` zeigte die deutsche Zielgruppen-Grafik und das Bildschirmfoto der deutschen Oberfläche ohne Hinweis. Die Grafik „Who we build the DMS for“ gibt es jetzt auf Englisch (`personas-skala.en.svg`, mit englischem Alternativtext). Eine englische Oberfläche gibt es noch nicht (#357) – das Bildschirmfoto bleibt deshalb deutsch und trägt in der englischen README den Hinweis, dass die Oberfläche derzeit nur auf Deutsch verfügbar ist. Die Tabelle der Installationswege sagt dort, dass die Anleitungen deutsch sind.

## Für Mitwirkende

- **Grafiken je Sprache:** Grafiken mit Text gibt es als `name.svg` (Deutsch) und `name.en.svg` (Englisch); `README.en.md` bindet nur die englischen ein, Bildschirmfotos der Oberfläche bis zur englischen Oberfläche mit Hinweis. Die Regel steht in `CONTRIBUTING.md` und `CONTRIBUTING.en.md`; ein Test prüft sie (auch: keine deutschen Beschriftungen auf den Abzeichen der englischen README).
- Das Werkzeug `docs/handbuch/werkzeuge/personas_grafiken.py` zeichnet die Skala in beiden Sprachen.
