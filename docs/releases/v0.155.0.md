## Neu

- **Dann-Karte „Feld ändern“** (#676): setzt nur die gewählten Felder einer Mappe – fester Wert, Text mit Platzhaltern wie beim Titel, bei Datumsfeldern auch `heute`, `heute+7` oder `heute-3`. Geprüft wird wie im Formular (Pflichtfelder, Auswahllisten, Verweise, Archivmodus); die Historie zeigt „durch Automatisierung ‚…‘“.
- **Dann-Karte „Aufgabe / Benachrichtigung“** (#676): an Personen, an alle aktiven Mitglieder einer Rolle oder an die Person in einem Feld der Mappe; Aufgaben mit Fälligkeit in N Tagen, Benachrichtigungen gebündelt. Wer die Mappe nicht sehen darf, bekommt die Aufgabe ohne Link an seiner eigenen Benutzer-Mappe.
- Im **Trockenlauf** zeigen beide Karten nur, was sie tun würden („Würde setzen: …“, „Würde Aufgabe an 2 Personen senden: …“).

## Handbuch

- Entwicklerhandbuch: Aufbau → Automatisierungen → **Dann-Karten**.

## Technik

- `server/src/automatisierung-karten.ts`; `Dienst.aufgabeAusAutomatisierung`.
- Tests: `server/test/automatisierung-karten.test.ts`, darunter das Beispiel „Vertrag – Kündbar bis in 7 Tagen → Aufgabe an Verantwortlich“.
- Keine Migration, keine neue Abhängigkeit.
