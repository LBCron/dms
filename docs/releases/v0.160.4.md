## Behoben

- **Keine ältere Version auf einer neueren Datenbank** (#714): Wird `:stabil` zurückgesetzt oder steht im Tag eine ältere Nummer als zuletzt, startet Ablago nicht mehr auf einer Datenbank, die schon eine neuere Version eingerichtet hat. Statt neue Daten (z. B. Spalten für Rechte oder Sperren) zu übersehen, bricht der Start mit dem Hinweis *Diese Datenbank stammt von einer neueren Version von Ablago* ab. Dasselbe gilt beim Wiederherstellen einer Sicherung aus einer neueren Version.
- **Workflow `:stabil`:** Der Schritt, der Pakete schreiben darf, behält das Anmeldezeichen nach dem Auschecken nicht mehr; Angaben zum Repository kommen über Umgebungsvariablen.

## Handbuch

- Administratorhandbuch „Aktualisieren“: Was ein Zurücksetzen von `:stabil` für dich bedeutet – noch nicht aktualisiert, schon aktualisiert (auf der neueren Version bleiben oder über die Sicherung zurück), neu eingerichtet ab 0.158.3.
