## Behoben

- **Paket entfernt, Dokumente warteten weiter:** Wer ein Paket entfernte, das Volltext liefert oder Dateien umwandelt (z. B. Office und E-Mail, Bildformate), sah an Dokumenten, die gerade darauf warteten, weiter „wartet auf Volltext“ bzw. „wartet auf Umwandlung“ – bis jemand „Neu erzeugen“ klickte. Jetzt räumt das Entfernen auf: Ohne Text steht am Dokument wieder, dass es für diesen Dateityp kein Paket gibt (ist ein anderes Paket zuständig, übernimmt es); mit Text von vorher bleibt der Text stehen.
