## Neu

- **Paket nur mit Ansichten** (#656): Zeigt eine Ansicht auf einen eigenen Mappentyp, der nicht ins Paket kommt, nennt die Prüfung ihn je Ansicht („muss beim Empfänger schon da sein“) mit **Mit aufnehmen** – der Export geht trotzdem. Der Typ bleibt über seine **Kennung** in der Ansicht statt still herauszufallen.
- **Beim Installieren** ordnet Ablago solche Typen dem Mappentyp mit derselben Kennung zu. Gibt es ihn nicht, wird die Ansicht **einzeln übersprungen** (mit ihren Unteransichten) – die Vorschau sagt es vorher, das übrige Paket wird installiert. Fehlt nur einer von mehreren Typen, kommt die Ansicht ohne ihn.

## Technik

- Paketformat: Ansichten können `fremde_typen: [{ kennung, name }]` tragen; Pakete damit brauchen `dms: ">=0.178.0"` (dms-registry: `pruefen.py`).
