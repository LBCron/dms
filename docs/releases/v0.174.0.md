## Neu

- **Farbige Seitenbilder für Pakete** (#716): Pakete können eine Seite jetzt auch in Farbe anfordern (`GET /dokumente/{id}/seiten/{nr}/scan?farbe=1`, PPM). Damit kann das Paket PDF/A die Archivfassung farbiger Rechnungen, die am Computer entstanden sind, farbig aufbauen statt in Graustufen (folgt mit PDF/A 1.1.0). Gleiche Grenzen wie bisher, kein neues Recht.
